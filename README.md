# shoelution-marketplace
Shoelution: an online marketplace for buying and selling new, pre-loved, and thrifted shoes of any brand, with size profiles, condition grading, and verified sellers.

## Setup
1. Install Node.js LTS from nodejs.org.
2. Copy .env.example to .env on your own computer.
3. Run npm install in the project folder.
4. Start the app with npm start.
5. Open http://localhost:3000 in your browser.
